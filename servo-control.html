Монитор порта · RX / TX 0 строк · 0 Б

В одной ленте видно всё: RX — что пришло от платы (включая телеметрию #S1=…;T=…), TX — что ушло на плату, SYS и ERR — сообщения самой страницы. Команда уходит кнопкой «Отправить» или клавишей Enter, стрелки ↑ и ↓ листают историю. Поддерживаются s1 <угол>, s2 <угол>, serva angle <угол>, а mb <текст> отправляет строку на micro:bit. Диапазон прошивки — 20…170°. «HEX» показывает байты, «Пауза» останавливает вывод, не закрывая порт.

Способ связи выбирается сверху: USB · провод — через Web Serial, плата подключена кабелем; Wi-Fi — через встроенный ESP8266 (Mega+WiFi R3), тогда достаточно указать адрес платы, например mega.local или её IP, и управлять с телефона без проводов. В режиме USB перед подключением закройте Serial Monitor в Arduino IDE — порт может быть открыт только одним приложением. После открытия порта плата перезагружается, поэтому первые ~2,5 секунды команды не отправляются. Данные никуда не уходят, обмен идёт напрямую с платой. Если плата не появляется в списке портов — нажмите «Драйвер платы».

Драйвер Arduino Uno

Браузер не имеет права ставить драйверы в систему — это делает установщик, который вы запускаете сами. Кнопка ниже отдаёт готовый install-driver.bat: он ставит два драйвера сразу — Arduino (ATmega16U2, официальные платы) и CH340 (платы-клоны), затем пересканирует устройства и печатает найденные COM-порты.

  1. Скачать установщик уже лежит рядом: driver\install-driver.bat
  2. Правый клик по файлу → «Запуск от имени администратора» → в окне UAC «Да».
  3. Вернитесь сюда и нажмите «Проверить плату»: страница покажет, какой драйвер увидела Windows.
Нажмите «Проверить плату», чтобы посмотреть, что видит браузер.

Официальному Uno R3 на Windows 10/11 драйвер не нужен — он встроен в систему, плата видна как «Arduino Uno (COMx)». Драйвер CH340 нужен только платам-клонам. Путь к установщику: driver\install-driver.bat.

Синхронизация через Firebase

Компьютер с платой публикует углы и телеметрию в Realtime Database, телефон читает и пишет те же значения. Служебные данные: cmd/a1, cmd/a2 — желаемые углы, state/* — что пришло с платы.

Синхронизация выключена — страница работает только с платой.

На телефоне откройте копию этой страницы: Web Serial там нет, но ползунки и показания работают через базу. Правила в консоли Firebase: {"rules":{"manipulator":{".read":true,".write":true}}}. Ссылка на базу = доступ к сервам, не публикуйте её.
